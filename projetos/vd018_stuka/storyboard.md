## Ligações (cada imagem antecipa a próxima frase)
hélice + bomba perto (pergunta) → avião despencando (o porquê do perigo) → mergulho real (prova do ângulo) → sirene (o
medo) → bomba solta reto (vai dar errado?) → congelado na pá (sim, daria) → garfo (a solução escondida) → arremesso
(funciona) → bomba real (é verdade) → puxão (novo problema) → piloto apagando (consequência) → manche sozinho (quem
pilota?) → piloto acorda → volta ao quadro 0 (loop).
